# GATE-MOCKTEST

A full-featured TCS-style online examination platform built for GATE mock tests, providing a realistic computer-based test experience with timed exams, MCQ/MSQ/NAT questions, automated evaluation, and exam-style navigation.

## Features

- 📝 GATE-style mock examinations
- ⏱️ Timed examinations with automatic submission
- ❓ MCQ, MSQ, and NAT question types
- 📊 Automated evaluation and scoring
- 🧭 Exam-style question navigation
- 🔖 Question marking and review
- 📑 Detailed test results
- 👨‍🎓 Student-facing test history
- 🔐 Secure examination workflow

## Purpose

The project aims to provide a realistic online examination environment similar to modern computer-based testing platforms, allowing GATE aspirants to practice under exam-like conditions.

## Tech Stack

- Frontend: React
- Backend: PHP
- Database: MySQL
- Authentication & Session Management
- REST APIs
